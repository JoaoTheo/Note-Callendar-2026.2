# 1. Requisitos Funcionais

| RF01 | O sistema deve permitir que o usuário realize login seguro validando credenciais de e-mail e senha.       |    Alta    |          RF12           |
| RF02 | O sistema deve permitir o cadastro de eventos contendo título, data, horário e categoria da atividade.    |    Alta    |          RF12           |
