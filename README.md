**Funcionalidades**

O Note Callendar é um sistema de agendas que faz mapeamento de tarefas e gestão ágil de tempo. O objetivo do programa é possibilitar ao usuário uma boa visualização de tarefas a serem realizadas e metrificar os tipos de tarefa.
